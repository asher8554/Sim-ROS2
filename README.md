# Sim-ROS2

MuJoCo + ROS 2 주행형 양팔 로봇 & LLM Robotics (로보월드 2026 부스) 강의 21편을 5장으로 압축한 HTML 교육자료입니다.

| 장 | 파일 | 주제 | 원본 강의 |
|---|---|---|---|
| 1 | [01_overview_env_mujoco.html](01_overview_env_mujoco.html) | 부스 패키지 · 개발 환경 · MuJoCo 기초 | 01~03 |
| 2 | [02_model_bridge_sensors.html](02_model_bridge_sensors.html) | 로봇 모델 · MuJoCo 브리지 · 센서/TF/Odom | 04~07 |
| 3 | [03_slam_navigation.html](03_slam_navigation.html) | SLAM · Nav2 주행 · 충돌 회피 · 순찰 데모 | 08~11 |
| 4 | [04_manipulation.html](04_manipulation.html) | MoveIt 양팔 · 엔드이펙터 제어 · Pick & Place · 컵 배달 | 12~15 |
| 5 | [05_llm_fms_extensions.html](05_llm_fms_extensions.html) | LLM 지령 · Task Pipeline · Web FMS · Final Mission · 확장(PID/LQR, Isaac Sim) | 16~21 |

## 보는 법

저장소를 내려받아 `index.html`을 브라우저로 엽니다. 외부 의존은 Pretendard 웹폰트(CDN) 하나이며, 오프라인이면 시스템 글꼴로 표시됩니다.

원본 슬라이드의 그림·영상은 용량 때문에 빼고 표와 도식으로 바꿨습니다.
